# Change Log

This file contains all the notable changes done to the Ballerina Xero Assets connector through the releases.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Remote methods for the Xero Assets API: `listAssets`, `createAsset`, `getAsset`, `listAssetTypes`,
  `createAssetType` and `getSettings`.
- A mock server and a test suite that covers every operation.
- Two examples: `asset_register_review` and `asset_type_onboarding`.
